# Fonts

Thaana (Dhivehi) fonts used when Fill language is Dhivehi:

| File | Family | Notes |
|------|--------|--------|
| `bolhu.ttf` | Bolhu Bold | [Thaana Type Foundry](https://thaana.com/) — SIL OFL 1.1 |
| `faruma.ttf` | Faruma | Widely used Thaana face; free for personal & commercial use |
| `waheed.otf` | MV Waheed | Classic Thaana face; free for personal & commercial use |

Bundled from the [dhivehifonts](https://github.com/iqzer0/dhivehifonts) collection.
